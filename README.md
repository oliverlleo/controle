# Sistema de Gerenciamento Financeiro

Sistema open source para gerenciamento financeiro pessoal.

## Tecnologias

- HTML5, CSS3, JavaScript
- Firebase (Authentication, Realtime Database)
- ApexCharts para gráficos
- Font Awesome para ícones

## Como executar

1. Configure suas credenciais do Firebase no arquivo js/script.js
2. Sirva os arquivos através de um servidor HTTP
3. Acesse index.html no navegador

## Estrutura

- index.html - Página principal do sistema
- login.html - Página de autenticação
- css/ - Arquivos de estilo
- js/ - Lógica da aplicação
